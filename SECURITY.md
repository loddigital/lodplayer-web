# Security Policy

## Supported Versions

At LOD Player, we take security seriously. We currently provide security updates only for the latest available version of the application. Please ensure you are always using the most recent version available on the official app stores.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you believe you have found a security vulnerability in the LOD Player application, our website, or our infrastructure, please report it to us directly. 

**🚨 Please do not report security vulnerabilities through public GitHub issues.**

**How to report:**
Please email your findings to **support.lodplayer@gmail.com**

**What to include:**
* A clear description of the vulnerability.
* Steps to reproduce the issue.
* Any relevant screenshots, logs, or platform details (e.g., Android version, TV model).

**What to expect:**
* We will acknowledge receipt of your vulnerability report within 48 hours.
* We will investigate the issue and keep you updated on the progress of the fix.
* Once the vulnerability is resolved, we will notify you before the patch is publicly released.

We appreciate your effort in responsibly disclosing your findings and helping us keep LOD Player safe for everyone.
