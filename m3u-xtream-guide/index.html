How to Add M3U and Xtream Codes API Playlists in LOD Player

LOD Player supports both Xtream Codes API logins and standard M3U or M3U8 playlist URLs across iOS, Android, and Android TV. You can enter credentials directly in the mobile app or use lodplayer.com/sync to auto-extract full get.php links and push playlists straight to your Smart TV.

Xtream Codes API vs. M3U Playlist URL: Which Should You Choose?

If your legal media provider gives you a server URL, username, and password, choosing Xtream Codes API in LOD Player is recommended. Xtream API cleanly separates Live TV, Movies (VOD), and Series into structured categories with metadata, episode grouping, and faster incremental updates.

If you have a direct .m3u or .m3u8 playlist URL (such as open public broadcasts, legal IPTV streams, or local home network playlists), select the M3U option. LOD Player parses large playlists rapidly and organizes groups automatically.

Automatic Credential Extraction from Full M3U Links

Many providers send a single long get.php URL that already embeds your host, port, username, and password (for example, http://server:8080/get.php?username=USER&password=PASS&type=m3u_plus). Both the LOD Player app and lodplayer.com/sync automatically detect this URL pattern.

Simply paste the full link into the Server URL field on the Xtream API tab: LOD Player extracts the base server address, username, and password into the right fields instantly, avoiding manual copy-paste errors.

Refresh Schedules, Custom User-Agent, and Multi-List Limits

When adding a playlist, you can configure how often LOD Player refreshes channel and VOD metadata (on startup, daily, every 3 days, weekly, or never). If your media server requires a specific client identifier, you can toggle off the default User-Agent and enter a custom User-Agent string.

A single LOD Player account supports managing and synchronizing up to 5 separate playlists across up to 5 devices, making it easy to keep regional broadcasts, personal media servers, and family profiles organized.

Troubleshooting Playlist Loading and Parental Controls

If a playlist fails to load, double-check that your server URL includes the exact http or https scheme and port number, and confirm there are no trailing spaces in your username or password. When using lodplayer.com/sync on Android TV, ensure your television displays an active 8-digit code and is connected to the internet.

To keep shared living-room televisions family-friendly, enable Hide Adult Channels (+18) when sending a playlist via lodplayer.com/sync or inside LOD Player settings. Category filtering hides matching adult groups automatically across your synced screens.

Frequently Asked Questions

What is the maximum number of playlists I can add in LOD Player? +

LOD Player supports up to 5 synchronized playlists across up to 5 connected devices per account.

Can I convert a full get.php M3U link into an Xtream Codes login? +

Yes. Paste your full get.php URL into the Server URL field on lodplayer.com/sync or inside LOD Player, and the parser automatically extracts the server host, username, and password.

Does LOD Player include built-in channels or playlists? +

No. LOD Player is strictly a media player developed by LOD Digital and contains zero built-in channels, streams, or subscriptions. Users must add their own legally acquired playlists.
